# External study input

Place the authorized `imputed_hourly_dataset.xlsx` here before reproduction. It is intentionally not distributed in this code-only package. The original input contains 26,304 hourly records and 30 columns; local identity is checked by `scripts/00_verify_reproducibility_inputs.py`.

Raw reconstruction and ablation inputs require separate authorized access. The applicable timestamp time-zone convention still needs to be stated by the author.
